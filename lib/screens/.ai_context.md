# AI_SCREENS_CONTEXT
LAST_UPDATE: 2026-10-24T11:48:00
STACK: Flutter(Dart 3.x)|MaterialApp|ThemeData.dark

## ENTRYPOINTS
- routes_definition: lib/main.dart (MeuAppTreino)
- api_client: lib/services/api_service.dart

## ROUTES_MAP
- /login: [auth] login_screen.dart -> entra no app via ApiService.fazerLogin
- /cadastro: [auth] cadastro_screen.dart -> cria conta via ApiService.criarConta
- /esqueceu-senha: [auth] esqueceu_senha_screen.dart -> solicita OTP por email
- /redefinir-senha: [auth] redefinir_senha_screen.dart -> valida OTP e redefine senha
- /home: [dashboard] home_screen.dart -> metricas de pontos, streak e atalhos
- /perfil: [user] profile_screen.dart -> dados do usuario, metricas e logout
- /alterar-nome: [user] change_name_screen.dart -> edita nome via ApiService.editarPerfil
- /alterar-senha: [user] change_password_screen.dart -> altera senha do usuario autenticado
- /treinos: [workout] treinos_screen.dart -> catalogo de rotinas e categorias
- /treino-menu: [workout] training_menu_screen.dart -> hub de opcoes de treino
- /dificuldade: [workout] dificuldade_treino_screen.dart -> seletor (iniciante/intermediario/avancado)
- /opcao-treinos: [workout] opcao_treinos_screen.dart -> listagem por dificuldade ou meus_treinos
- /meus-treinos: [workout] opcao_treinos_screen.dart(dificuldadeFlag: 'meus_treinos')
- /criar-treino | /criar: [workout] criar_exercicio_screen.dart -> form de criacao de treino/exercicios
- /leaderboard: [social] leaderboard_screen.dart -> ranking com seletor Pontuação Semanal vs Streak, pódio duplo e tabela
- /amigos: [social] amigos_screen.dart -> CRUD completo de amigos, solicitacoes e busca real por nome conectada à API
- dynamic_push: [workout] treino_selecionado_screen.dart -> detalhe, salvar e execucao de treino

## NAVIGATION_FLOWS
- auth_flow: /login -> (/cadastro | /esqueceu-senha -> /redefinir-senha) -> /home
- workout_flow: /home -> /treino-menu -> /dificuldade -> /opcao-treinos -> treino_selecionado_screen.dart
- custom_workout_flow: /treino-menu -> /criar-treino -> /meus-treinos
- social_flow: (/home | /perfil) -> (/leaderboard <-> /amigos)
- profile_flow: /home -> /perfil -> (/alterar-nome | /alterar-senha | /login[logout] | /leaderboard | /amigos)

## UI_DESIGN_RULES
- theme_colors: Background=#0D1117, Primary/Accent=#00E676 (verde neon), Surface=#1E232A, Error=#E91E63
- state_pattern: StatefulWidget com setState() local; chamadas HTTP via ApiService() Singleton
- feedback_rule: Usar ScaffoldMessenger.of(context).showSnackBar() com cores tematicas para feedback
- no_direct_http: Nenhuma tela pode importar 'package:http/http.dart'; usar sempre ApiService
- relative_paths: Referências a arquivos de telas e componentes devem ser relativas à raiz (ex: lib/screens/login_screen.dart)
