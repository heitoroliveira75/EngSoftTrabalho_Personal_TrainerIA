## ARCH_RULES_DB_API
- rule1_security: SUPABASE_SERVICE_ROLE_KEY restrita a BD/.env e variáveis no Render; nunca exposta ao Flutter ou versionada no Git.
- rule2_rls: RLS obrigatório em todas as tabelas public.* (ENABLE ROW LEVEL SECURITY).
- rule3_standard_response: Toda rota da API responde {"sucesso": bool, "mensagem": str, "dados_opcionais": ...}.
- rule4_cors: CORS liberado com allow_origins=["*"] para suportar emulador (10.0.2.2), web, mobile e clientes remotos.
- rule5_rpc_analytics: Cálculos analíticos, busca e amizades executam com fallback automático via RPC SECURITY DEFINER para contornar bloqueios indevidos de RLS.
- rule6_relative_paths: Todo arquivo citado neste contexto deve ser referenciado a partir da raiz do repositório (ex: BD/api.py).
